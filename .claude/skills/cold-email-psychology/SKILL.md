# Psychology lens

**Load:** `agents/cold-email/knowledge/07-psychology.md`. Supporting studies are in report 06 §4 and report 03 §B.

## As a review lens (run on any draft)
For each part of the email, ask which principle it uses, which it violates, and what the fix is:

| Part | Principles to check |
|---|---|
| Subject | Self-relevance (name), curiosity gap (not clickbait), no deception |
| Hook | Real reason (Langer), relevance over flattery, specificity (evidentiality) |
| Problem | Loss aversion, their words (fluency), safe space / social proof |
| Proof | Social proof (a peer of the same size), authority × personalization, precise numbers |
| Offer | Reciprocity (give first), risk reversal, problem awareness |
| CTA | Foot in the door, low perceived effort, detachment (no neediness) |
| Whole email | Fluency (grade 3–7, short), perceived effort (looks quick to answer), peer tone |
| Sequence | Consistency of the "envelope" only if value came first; closure in email 4; a new reason each touch |
| Replies | Speed (within 1 hour), gratitude, mirroring tone |

## As an explainer
When the user asks *why* something works, name the principle, the study (author and year), the effect size if known, and how strong the evidence is (randomized study / measured data / practitioner claim). Never overstate weak or vendor evidence.

## Ethics guardrail
Persuasion means making a real thing easy to say yes to. **Reject** any tactic that fakes scarcity, similarity, prior contact, proof or urgency. Cite Eric's deceptive test (10%) vs an honest free offer (30%).

## Output
A table of principle → status (used / missing / violated) → a one-line fix, plus the top 2 changes that would most raise the reply probability.
